## Why this source was selected

The recovered source contains the same current 12-project portfolio set and positioning visible in the Site v104 projection, including Mackenzie Cramblit, Morganics, LinkedIn Personal Brand, Intellignce, Bits HR Link, Fakhr-e-Qoum, Jules Capital Partners, BW Sports, Edlytics, NiceMD.ai, Al Faraj Media and Accessorize by HL.

The source also contains the current service set, lead flow, calendar/lead integrations, Sera v9 source, build scripts, portfolio data, and Hostinger packaging support.

The GitHub `main` branch is an older September Next.js baseline and must not be treated as the source of truth for the current site.

## Important distinction

The editable source and the captured production filesystem are related but not identical representations.

The 21 October production recovery captured the current Hostinger tree and preserved exact deployed bytes for static output, Sera runtime and lead endpoints. It is evidence and rollback material, not the maintainable editable source.

The 21 October adoption handoff documented a local source adoption commit, but its original parent commit was never published to GitHub. That handoff remains evidence only and must not be merged wholesale.
